# Live harness

`breakpoints.html` exercises breakpoints from DevTools. Run `npm install && npm run dev` here, then open `/breakpoints.html`.

The trace viewer pages live in the `@andymitchell/logging-ui-react` repo's `testing/live`.

# Troubleshooting

## Using old/cached npm module

It might be cached. Make Vite do-over with `npm run clean-dev`
